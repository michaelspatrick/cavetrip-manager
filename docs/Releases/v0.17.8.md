# CaveTrip Manager v0.17.8 — Email Settings & Trip Status Cleanup

This release includes all requested admin cleanup and outgoing email configuration.

## Included
- Fixes the blank Trips status display with readable status badges.
- Simplifies admin-editable trip statuses to Draft, Open for Signup, Signup Closed, and Cancelled.
- Keeps Completed as a system/workflow status rather than a normal manual choice.
- Migrates legacy `waiver_signing`, `finalized`, and `active` statuses to `open` and adds `closed`.
- Places the public Signup Link directly beneath each trip name in the Trips list.
- Removes General Area and Status from the Caves listing; displays State instead.
- Adds Admin → Email Settings.
- Supports Amazon SES through SES SMTP endpoints and custom SMTP servers.
- Stores SMTP passwords encrypted at rest with a server-local AES-256-GCM key.
- Adds a Send Test Email workflow with real SMTP error reporting.
- Email service is reusable by future invitation, waiver, and reminder jobs.

## Amazon SES note
Use SES **SMTP credentials**, not an IAM access key/secret. For SES, choose the AWS region; CaveTrip Manager derives the SMTP host automatically. SES verified-identity and sandbox restrictions still apply.

## Apply
```bash
unzip cavetrip-manager-v0.17.8-email-settings-status-ui.zip
cd cavetrip-manager-v0.17.8-email-settings-status-ui
./scripts/apply-release.sh /opt/cavetrip-manager
cd /opt/cavetrip-manager
php migrate.php
php -l app/Controllers/EmailSettingsController.php
php -l app/Services/EmailSettingsService.php
php -l app/Services/EmailService.php
php -l app/Services/SmtpMailer.php
git diff
git status
git add .
git commit -m "Release v0.17.8 email settings and status cleanup"
git push origin main
sudo /var/www/trips.sixridgesgrotto.org/update.sh
```

## Test
1. Trips list shows a visible status badge.
2. Signup Link appears under the trip name and opens the public signup page.
3. Edit Trip only exposes Draft, Open for Signup, Signup Closed, and Cancelled (Completed remains system-controlled).
4. Caves list has Name, Landowner, County, State, Edit; no General Area or Status columns.
5. Admin sidebar has Email Settings.
6. Save Amazon SES or custom SMTP settings.
7. Send a test email and confirm success/failure feedback.
8. Back up `storage/keys/mail.key` with the application; losing it makes stored SMTP passwords undecryptable.
