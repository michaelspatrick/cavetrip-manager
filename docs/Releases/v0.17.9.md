# CaveTrip Manager v0.17.9 — Trip Progress Bar Fix

This hotfix corrects the trip dashboard progress indicators.

## Changes
- Replaces the conflicting Bootstrap `.progress` markup with CaveTrip Manager-specific progress classes.
- Roster capacity now visibly fills based on registered participants / maximum attendees.
- Adds a waiver-signing progress bar based on signed participants / active roster.
- Shows percentage captions for both metrics.
- Adds accessible progressbar ARIA attributes.
- Cache-busts `app.css` to v0.17.9.
- No database migration is required.

## Apply
```bash
unzip cavetrip-manager-v0.17.9-progress-bars.zip
cd cavetrip-manager-v0.17.9-progress-bars
./scripts/apply-release.sh /opt/cavetrip-manager

cd /opt/cavetrip-manager
git diff
git add .
git commit -m "Release v0.17.9 trip progress bars"
git push origin main

sudo /var/www/trips.sixridgesgrotto.org/update.sh
```
