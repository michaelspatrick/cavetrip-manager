# CaveTrip Manager v0.18.1 — SMTP Diagnostics

Adds a separate **Test SMTP Connection** action to Email Settings. It verifies the saved SMTP host/port, TLS/SSL negotiation, and SMTP authentication without sending a message. Existing **Send Test Email** remains available to test actual delivery.

No database migration is required.

## Test
1. Save Email Settings.
2. Click **Test SMTP Connection**.
3. Confirm the success message names the actual configured endpoint and reports authentication successful.
4. Then use **Send Test Email** to verify end-to-end delivery.
