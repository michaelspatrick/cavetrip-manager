# CaveTrip Manager v0.17.4

## User Grotto & Trips Hotfix

- Restores `BaseController::requireLogin()` used by the v0.17.3 trip visibility code.
- Fixes the `/trips` fatal error caused by a stale BaseController deployment.
- Replaces the Super Admin `Grotto ID` number field with a Grotto dropdown.
- Super Admins can move users between grottos from the Edit User screen.
- Admin, Member, and Guest accounts are required to have a grotto.
- Installation-level Super Admin accounts may remain unassigned.
- Removes the unused Status column from the Landowners list.

No database migration is required for this release.
