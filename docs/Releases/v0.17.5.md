# CaveTrip Manager v0.17.5 — Layout & Authentication Hotfix

This patch fixes the repeated PHP warning:

`Undefined array key "name" in app/Views/layouts/app.php`

It also re-ships the corrected `BaseController` containing `requireLogin()` so the Trips controller dependency is present even if a prior patch was only partially applied.

## Changes

- Restores `name => CaveTrip Manager` in `config/version.php`.
- Makes the shared layout defensive if `name` is ever omitted from release metadata again.
- Keeps the application title/footer working without PHP warnings.
- Re-ships the corrected `BaseController::requireLogin()` implementation.
- Bumps version to 0.17.5 / build 2026.09.03.6.

No database migration is required.

## Apply to Git working tree

```bash
unzip cavetrip-manager-v0.17.5-layout-auth-hotfix.zip
cd cavetrip-manager-v0.17.5-layout-auth-hotfix
./scripts/apply-release.sh /opt/cavetrip-manager

cd /opt/cavetrip-manager
git diff
git add .
git commit -m "Release v0.17.5 layout and authentication hotfix"
git push origin main

sudo /var/www/trips.sixridgesgrotto.org/update.sh
```

## Verify

```bash
php -l /var/www/trips.sixridgesgrotto.org/app/Controllers/BaseController.php
php -l /var/www/trips.sixridgesgrotto.org/app/Views/layouts/app.php
php -l /var/www/trips.sixridgesgrotto.org/config/version.php
```

Then test `/dashboard`, `/trips`, `/caves`, `/landowners`, `/trip-reports`, and `/users`.

If `/trips` still reports `undefined method requireLogin()` after deploying this release, verify the live controller directly:

```bash
grep -n "function requireLogin" /var/www/trips.sixridgesgrotto.org/app/Controllers/BaseController.php
```

You should see the method definition.
