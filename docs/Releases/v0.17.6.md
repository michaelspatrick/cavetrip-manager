# CaveTrip Manager v0.17.7 — Integrated Waiver Signup

This release completes the public signup/waiver path and simplifies participant medical data.

## Changes

- The branded public Trip Signup page now shows the selected waiver **before** the signature pad.
- Trip registration and waiver signature are saved together in one transaction.
- Signature pad supports mouse, trackpad, touch, phone/tablet, and stylus through Pointer Events.
- Requires an explicit "I have read and agree" acknowledgement when a waiver is configured.
- Minor participants dynamically reveal Guardian Name and Guardian Email; both become required.
- The signature label changes to **Parent / Guardian Signature** for minors.
- Replaces Allergies, Medications, Conditions, and Physical Limitations with one **Medical / Safety Notes** field.
- Migration preserves existing values from the four legacy medical fields by appending them to Medical / Safety Notes before dropping the old columns.
- Updates the internal participant-add/remove controller to the current BaseController and AuditLogService APIs.
- Existing individual `/sign?token=...` links remain available for participants who were added administratively or existed before this release.

## Apply to the Git working tree

```bash
./scripts/apply-release.sh /opt/cavetrip-manager
cd /opt/cavetrip-manager
git diff
git add .
git commit -m "Release v0.17.7 integrated waiver signup"
git push origin main
```

Then deploy normally:

```bash
sudo /var/www/trips.sixridgesgrotto.org/update.sh
```

The deployment must run `php migrate.php` so migration `20260903_177000_consolidate_medical_fields.php` is recorded and applied.

## Test first

1. Open a trip that has an active waiver template and copy its public signup link.
2. Confirm the signup page has no admin sidebar and displays the grotto branding.
3. Confirm only **Medical / Safety Notes** appears; the four old medical fields are gone.
4. Confirm Guardian Name/Email are hidden until **Participant is a minor** is checked.
5. Check minor and confirm both guardian fields become required and the signature heading changes to Parent / Guardian Signature.
6. Read the displayed waiver, check acknowledgement, sign, and submit.
7. In Manage Trip, confirm the participant is present and marked signed.
8. Repeat once from a phone/touch device if available.
9. Verify legacy participant medical information was preserved in `medical_notes` before the old columns were removed.
