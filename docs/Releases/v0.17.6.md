# CaveTrip Manager v0.17.6
## Public Signup Branding and Responsive Signatures

This release changes the tokenized participant-facing pages into a public branded experience and improves signature-pad compatibility.

### What changed

- `/trip/signup?token=...` no longer uses the authenticated admin/sidebar layout.
- Public signup displays the grotto name and configured grotto logo.
- Trip summary fields now have proper label/value spacing and responsive cards.
- Meeting/participant instructions are visually separated from the trip summary.
- `/sign?token=...` also uses the public branded layout.
- Signature input uses Pointer Events, covering modern desktop mouse/trackpad, touchscreens, phones, tablets, and styluses with one input path.
- Signature canvas remains responsive without erasing ink during viewport changes.
- The signature lookup no longer references the removed `trips.cave_description` column.
- Grotto logo/name/website metadata is included in public trip and signature queries.

### Important waiver workflow note

The application already stores participant signature images, signed timestamp, IP address, user agent, and signature token, and the finalized waiver renderer can merge signatures into the final document. This release improves the signature capture UI and public presentation. It does **not** yet change the legal/consent workflow to display the full waiver text immediately above the signature pad; that should be addressed before calling the waiver workflow complete.

### Apply

```bash
unzip cavetrip-manager-v0.17.6-public-signup-signatures.zip
cd cavetrip-manager-v0.17.6-public-signup-signatures
./scripts/apply-release.sh /opt/cavetrip-manager

cd /opt/cavetrip-manager
git diff
git add .
git commit -m "Release v0.17.6 public signup branding and signatures"
git push origin main

sudo /var/www/trips.sixridgesgrotto.org/update.sh
```

No database migration is required.

### Test first

1. Open a trip share link in a private/incognito browser window. Confirm there is no sidebar or Logout button.
2. Confirm the Six Ridges Grotto logo/name appears at the top.
3. Confirm Cave, Leader, and Roster labels have clear spacing from their values.
4. Submit a test signup.
5. Open that participant's `/sign?token=...` link on desktop and on a phone.
6. Draw, clear, redraw, and save a signature.
7. Confirm the saved signature preview appears after saving.
