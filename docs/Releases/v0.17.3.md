# CaveTrip Manager v0.17.3 — Trip & Cave Privacy Cleanup

This is a focused privacy/UX release on top of v0.17.2.

## Changes

- Removes GPS Latitude, GPS Longitude, and legacy General Area from the Cave form/service and defensively drops those database columns if they still exist.
- Keeps cave State, County, landowner, access directions, parking/access notes, gate/lock code, and sensitive notes.
- Removes the Trip-level `Cave / Permission Area Description` field and drops `trips.cave_description`.
- `{{CAVE_DESCRIPTION}}` in generated waivers is now derived from the selected cave's name, county, and state.
- Renames `Core Group` to **Members** in the UI; the stored database value remains `core_group` for compatibility.
- Renames `Selected Members` to **Selected Users**.
- Adds inline explanations for all four visibility choices.
- Renames `Leader Notes` to **Trip Leader / Internal Notes** and clearly marks it as non-public.
- Enforces trip visibility server-side:
  - Admin/Super Admin: all grotto trips.
  - Members: Members-visible trips plus trips they lead or have been explicitly added to.
  - Invite Link: hidden from normal trip lists; available by signup token, and then to the participant after signup.
  - Private/Selected Users: not visible by guessed trip ID unless the user is leader/admin or an explicit participant.
  - Guests: only trips they are participants in.
- Only the trip leader or Admin/Super Admin may edit or cancel a trip.
- Cave routes continue to require Member/Admin access; Guests cannot browse the cave database.

## Important migration note

The migration permanently drops legacy precise cave GPS columns and the obsolete `trips.cave_description` column. Existing finalized waivers are unaffected because their rendered HTML is immutable.

## Apply

```bash
unzip cavetrip-manager-v0.17.3-trip-cave-privacy-cleanup.zip
cd cavetrip-manager-v0.17.3-trip-cave-privacy-cleanup
./scripts/apply-release.sh /opt/cavetrip-manager

cd /opt/cavetrip-manager
git diff
git add .
git commit -m "Release v0.17.3 trip and cave privacy cleanup"
git push origin main

sudo /var/www/trips.sixridgesgrotto.org/update.sh
```

## Test

1. Open `/caves/edit?id=1`: no General Area or GPS controls should exist.
2. Edit a trip: visibility should show Members / Selected Users / Invite Link / Private with help text.
3. The trip form should no longer contain Cave / Permission Area Description.
4. Internal notes should be labeled Trip Leader / Internal Notes.
5. As a normal Member, verify an Invite Link or Private trip does not appear unless you lead it or are explicitly on it.
6. As a Guest, verify `/caves` is inaccessible and only joined trips appear under My Trips.
7. Finalize a test waiver and verify `{{CAVE_DESCRIPTION}}` renders from cave name/county/state.
