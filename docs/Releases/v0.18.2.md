# CaveTrip Manager v0.18.2 — Admin Flash Messages Hotfix

Fixes a UI bug in the authenticated/admin layout that prevented success and error flash messages from being displayed. The SMTP diagnostic actions in v0.18.1 were setting useful success/error messages correctly, but the admin layout never rendered them.

After installing, **Test SMTP Connection** and **Send Test Email** will show either a green success alert or a red diagnostic error after the page reloads. This also restores visible feedback for other admin actions that use Session::flash().

No database migration is required.
